# Saptapper 処理フロー

## 全体フロー

```
┌─────────────────────────────────────────────────────────────────┐
│  ROM ファイル (.gba)                                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  1. ROM 読み込み (Cartridge::LoadFromFile)                       │
│     - ファイル検証                                               │
│     - メモリにロード                                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. MusicPlayer2000 ドライバ検出 (Mp2kDriver::Inspect)           │
│                                                                 │
│  ┌──────────────────┐                                           │
│  │ FindSelectSongFn │ ← 30バイト固定パターンで検索               │
│  │ (m4aSongNumStart)│   曲選択関数を特定                        │
│  └────────┬─────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌──────────────────┐                                           │
│  │ FindSongTable    │ ← SelectSongFn + 40 バイト目から          │
│  │ (song_table)     │   曲テーブルのポインタを読み取り          │
│  └────────┬─────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌──────────────────┐                                           │
│  │ FindMainFn       │ ← SelectSongFn 周辺を検索                 │
│  │ (m4aSoundMain)   │   bl (branch-link) 命令の解析             │
│  └────────┬─────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌──────────────────┐                                           │
│  │ FindInitFn       │ ← MainFn の前方 0x100 バイトを検索        │
│  │ (m4aSoundInit)   │   push/ldr パターンマッチング             │
│  └────────┬─────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌──────────────────┐                                           │
│  │ FindVSyncFn      │ ← InitFn 周辺を検索                       │
│  │ (m4aSoundVSync)  │   複数パターン対応                        │
│  └────────┬─────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌──────────────────┐                                           │
│  │ ReadSongCount    │ ← SongTable を走査                        │
│  │ (曲数)           │   無効エントリまでカウント                │
│  └──────────────────┘                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. GSF ドライバインストール (Mp2kDriver::InstallGsfDriver)      │
│                                                                 │
│  ROM 内の空き領域に GSF ドライバ (m4a-gsf.s) を書き込み          │
│                                                                 │
│  ┌─────────────────────────────────────────────────┐            │
│  │  GSF Driver Block (約 200 バイト)               │            │
│  │  ├─ main: ARM→THUMB 切り替え                   │            │
│  │  ├─ init: m4aSoundInit 呼び出し + IRQ 設定     │            │
│  │  ├─ main_loop: m4aSoundMain + VSyncIntrWait    │            │
│  │  ├─ irq_handler: V-Blank 割り込み処理          │            │
│  │  ├─ vsync_callback: m4aSoundVSync 呼び出し     │            │
│  │  └─ 関数ポインタ: InitFn, SelectSongFn,        │            │
│  │       MainFn, VSyncFn, songindex               │            │
│  └─────────────────────────────────────────────────┘            │
│                                                                 │
│  ROM の先頭 (0x8000000) に ARM 分岐命令を書き込み                │
│  → GSF ドライバへジャンプ                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  4. GSF ファイル出力                                             │
│                                                                 │
│  ┌─────────────────────────────────────────────────┐            │
│  │ gsflib (例: game.gsflib)                        │            │
│  │ ├─ PSF ヘッダ (version=0x22 for GSF)            │            │
│  │ ├─ 圧縮済み ROM データ (zlib)                   │            │
│  │ │   - エントリポイント: 0x8000000               │            │
│  │ │   - ロードアドレス: 0x8000000                 │            │
│  │ │   - ROM 全体を含む                            │            │
│  │ └─ タグ (オプション)                            │            │
│  └─────────────────────────────────────────────────┘            │
│                                                                 │
│  ┌─────────────────────────────────────────────────┐            │
│  │ minigsf (例: game_0001.minigsf, game_0002...)   │            │
│  │ ├─ PSF ヘッダ                                   │            │
│  │ ├─ 圧縮済みデータ                               │            │
│  │ │   - 曲番号 (songindex) のみ                   │            │
│  │ │   - GSF ドライバの songindex を上書き         │            │
│  │ └─ タグ                                         │            │
│  │     - _lib: gsflib ファイル名                   │            │
│  │     - gsfby: 作成者名                           │            │
│  └─────────────────────────────────────────────────┘            │
│                                                                 │
│  重複曲のスキップ (FindIdenticalSong)                           │
│  → 同じ曲データを指すエントリは出力しない                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  出力ファイル                                                    │
│  ├─ game.gsflib        (ROM + GSF ドライバ)                      │
│  ├─ game_0001.minigsf  (曲1)                                    │
│  ├─ game_0002.minigsf  (曲2)                                    │
│  └─ ...                                                         │
└─────────────────────────────────────────────────────────────────┘
```

## GSF 再生時の動作

```
GSF プレイヤー
    │
    ▼
GBA エミュレータコア起動
    │
    ├─ gsflib をメモリ (0x8000000〜) にロード
    ├─ minigsf で songindex を上書き
    │
    ▼
0x8000000 から実行開始
    │
    ├─ ARM 分岐命令 → GSF ドライバへジャンプ
    │
    ▼
GSF ドライバ (m4a-gsf.s)
    │
    ├─ m4aSoundInit() 呼び出し
    ├─ IRQ ハンドラ設定 (V-Blank 割り込み)
    ├─ m4aSongNumStart(songindex) 呼び出し
    │
    ▼
メインループ
    │
    ├─ m4aSoundMain() 呼び出し
    ├─ VSyncIntrWait (V-Blank 待ち)
    │     │
    │     └─ IRQ 発生時: m4aSoundVSync() 呼び出し
    │
    └─ 繰り返し (ループ再生)
```

## 関数検出の依存関係

```
FindSelectSongFn ─────────────────────────────────┐
       │                                          │
       ▼                                          ▼
FindSongTable ◄──────────────────────────── FindMainFn
       │                                          │
       ▼                                          ▼
ReadSongCount                              FindInitFn
                                                  │
                                                  ▼
                                           FindVSyncFn
```

**検出失敗時の連鎖:**
- SelectSongFn が失敗 → 全て失敗
- MainFn が失敗 → InitFn, VSyncFn が失敗
- InitFn が失敗 → VSyncFn が失敗

## 主要定数・オフセット

| 名前 | 値 | 説明 |
|------|-----|------|
| ROM ベースアドレス | 0x08000000 | GBA の ROM 領域開始アドレス |
| kInitFnOffset | GSF ドライバ内 | m4aSoundInit ポインタ位置 |
| kSelectSongFnOffset | GSF ドライバ内 | m4aSongNumStart ポインタ位置 |
| kMainFnOffset | GSF ドライバ内 | m4aSoundMain ポインタ位置 |
| kVSyncFnOffset | GSF ドライバ内 | m4aSoundVSync ポインタ位置 |
| gsf_driver_size() | 約 200 バイト | GSF ドライバブロックのサイズ |

## BytePattern によるマスク付き検索

```cpp
// 例: FindInitFn のパターン
BytePattern{
    "\x70\xb5\x00\x48\x02\x21\x49\x42\x08\x40"sv,  // バイト列
    "xx?xxxxxxx"sv                                  // マスク (? = 任意)
}

// 0x70 0xb5 = push {r4-r6, lr}
// 0x?? 0x48 = ldr r0, [pc, #imm] (即値は ROM 依存)
```

## ファイル構成

| ファイル | 役割 |
|----------|------|
| main.cpp | CLI エントリポイント、引数解析 |
| saptapper.cpp | 高レベル処理 (Inspect, ConvertToGsfSet) |

| gsf_writer.cpp | GSF/minigsf ファイル出力 |
| psf_writer.cpp | PSF フォーマット (GSF のベース) |

| arm.hpp | ARM 命令ユーティリティ |
| m4a-gsf.s | GSF ドライバ (ARM アセンブリ) |
